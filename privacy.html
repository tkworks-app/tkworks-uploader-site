プライバシーポリシー
Privacy Policy

最終更新日 / Last updated: 2026-11-06

本ポリシーは、TK Works（以下「当方」）が使用するデスクトップ用ツール「TK Works Uploader」（以下「本ツール」）における、 Google アカウントおよび YouTube のデータの取り扱いについて定めるものです。 本ツールは当方が自社の YouTube チャンネルを運用するためだけに使用しており、一般には提供していません。

This Privacy Policy explains how "TK Works Uploader" ("the Tool"), a desktop tool used by TK Works ("we"), handles Google account and YouTube data. The Tool is used only by TK Works to operate its own YouTube channels and is not offered to the public.

1. YouTube API サービスの利用 / Use of YouTube API Services

本ツールは YouTube API サービスを利用しています。本ツールを利用することで、 YouTube 利用規約に同意したものとみなされます。 Google によるデータの取り扱いについては、Google プライバシーポリシーをご覧ください。

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

2. アクセスする情報 / Information we access

本ツールは、利用者が Google アカウントで許可した範囲で、次の情報にアクセスします。

  • 認可したアカウントの YouTube チャンネルの ID と名前（アップロード先の確認のため）
  • そのチャンネルの再生リストの ID と名前（動画を追加する再生リストの確認のため）
  • そのチャンネルにアップロードした動画の ID・タイトル・公開状態・公開日時・再生回数・高評価数・コメント数（投稿状況の確認のため）

また、利用者の PC にある動画ファイルと、タイトル・説明・タグなどの情報を、利用者のチャンネルにアップロードします。

With the permissions you grant, the Tool accesses: the ID and name of the YouTube channel of the authorized account (to verify the upload destination); the IDs and names of that channel's playlists (to verify the playlists to add videos to); and the ID, title, privacy status, publish time, view count, like count and comment count of videos uploaded to that channel (to check their status). The Tool also uploads video files on your PC, together with their title, description and tags, to your channel.

3. 保存場所 / Where data is stored

Google から発行される認証情報（アクセストークン・リフレッシュトークン）と、アップロードの記録・投稿状況の一覧は、 本ツールを実行している PC の中にのみ保存されます。 当方が運用するサーバーは存在せず、これらの情報が当方や第三者に送信されることはありません。 本ツールが通信する相手は Google（YouTube Data API と OAuth）だけです。

The credentials issued by Google (access and refresh tokens), upload records and the list of video status are stored only on the PC that runs the Tool. We operate no servers, and this information is never sent to us or to any third party. The Tool communicates only with Google (YouTube Data API and OAuth).

4. 利用目的と第三者提供 / Use and sharing

取得した情報は、上記 2 の目的（動画のアップロード、アップロード先・再生リストの確認、投稿状況の確認）にのみ使用します。 広告への利用、販売、第三者への提供は行いません。

The information is used only for the purposes in section 2 (uploading videos, verifying the destination channel and playlists, and checking video status). It is never used for advertising, sold, or shared with third parties.

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に従います。

The Tool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. アクセスの取り消しと削除 / Revoking access and deletion

本ツールへのアクセス許可は、Google アカウントの サードパーティ製のアプリとサービスのページからいつでも取り消せます。 PC に保存された認証情報と記録は、本ツールのフォルダから該当するファイルを削除することで消去できます。

You can revoke the Tool's access at any time from the third-party apps & services page of your Google account. Credentials and records stored on the PC can be erased by deleting the corresponding files in the Tool's folder.

6. 本ポリシーの変更 / Changes to this policy

本ポリシーは必要に応じて改定されることがあります。重要な変更がある場合は本ページで告知します。

We may update this policy as needed; material changes will be posted on this page.
