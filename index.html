TK Works Uploader

TK Works の社内ツール / Internal tool of TK Works

概要 / Overview

TK Works Uploader は、TK Works が運営する YouTube チャンネルに、自社で制作した動画をアップロードするための デスクトップ用のコマンドラインツールです。TK Works が自社の作業のためだけに使用しており、一般には提供していません。

TK Works Uploader is a desktop command-line tool that TK Works uses to upload its own videos to the YouTube channels it operates. It is used only by TK Works for its own work and is not offered to the public.

主な機能 / What it does

  • 動画を非公開でアップロードし、タイトル・説明・タグなどを設定します。公開や予約は YouTube Studio で手動で行います。
    Uploads videos as private with their title, description and tags. Publishing and scheduling are done manually in YouTube Studio.
  • アップロードした動画を、チャンネルの再生リストに追加します。
    Adds uploaded videos to the channel's playlists.
  • アップロード先が正しいチャンネルかを、アップロードの直前に確認します。
    Verifies the destination channel right before each upload.
  • 投稿した動画の公開状態・再生回数などを読み取り、手元の一覧ファイルに書き出します。
    Reads the status and statistics of uploaded videos and writes them to a local list file.

本ツールは YouTube API サービスを利用しています。 This tool uses YouTube API Services.
