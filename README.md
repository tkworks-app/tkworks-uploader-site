# TK Works Uploader — Website

Home page and privacy policy for **TK Works Uploader**, the internal tool TK Works uses to upload videos
to its own YouTube channels. These pages are required by the Google OAuth consent screen.
Published via GitHub Pages. This repository contains **no tool source code and no credentials**.

- `index.html` — Home page (Japanese main, English secondary)
- `privacy.html` — Privacy Policy (bilingual)
- `styles.css` — Shared styles (same as the Message Assistant for eBay site)
- `.nojekyll` — Serve files as-is

URLs (after Pages is enabled):

- https://tkworks-app.github.io/tkworks-uploader-site/
- https://tkworks-app.github.io/tkworks-uploader-site/privacy.html
